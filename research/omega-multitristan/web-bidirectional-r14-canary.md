# Omega Multi-Tristan / Web bidirectional R14 - Public canary

## Purpose
This is a deliberately minimal, public, non-secret round-trip challenge to establish a bounded exchange from an authorized GitHub publishing connector to three user-owned Windows machines through HTTPS. It is **not** a scientific certification, a remote-control instruction, or authorization for inbound exposure.

## Challenge
- Marker: OMEGA-WEB-BIDIRECTIONAL-R14-20261019-CANARY-V1
- Scenario: two-node arithmetic averaging on four rational inputs.
- Inputs: (2, 6, 10, 14).
- First average pair (0,1): (4,4,10,14).
- Then average pair (2,3): (4,4,12,12).
- Initial and final sums: 32.
- Full four-way average: 8.
- The two-edge graph is disconnected: repeated averaging alone does not yield a global consensus.
- A successful round trip requires HTTPS read-back with HTTP 200 and byte-level SHA-256 matching on the fetching machines.

## Related mathematical context
The R13 synthetic experiment establishes that the special three-node fixed-sweep identity (P-H)^2=-(P-H)/8 does not hold universally for arbitrary graph topologies. It also illustrates that disconnected graphs can preserve separate component means. These facts must not be generalized to untested physical systems.
