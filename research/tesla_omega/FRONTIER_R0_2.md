# TESLA-OMEGA Frontier R0.2

R0.2 turns the R0.1 research kernel into a bounded topology-screening experiment.

## Model court

The screening model uses identical LC resonators with magnetic coupling only on graph edges:

`L_matrix = L (I + k A)`

and identical capacitances:

`C_matrix = C I`

For adjacency eigenvalue lambda_i, the ideal modal frequency is:

`f_i = f0 / sqrt(1 + k lambda_i)`

This is a network surrogate. It is **not** a Maxwell field solution and does not model radiation, conductor loss, dielectric loss, parasitic capacitance, or thermal limits.

## Search court

For n <= 6, every labeled tree is generated by Prufer sequences and exact graph-isomorphism deduplication reduces the set to unlabeled structural classes.

For n=6 there are six unlabeled trees. All candidates have the same node count and edge count, so the first comparison keeps a simple topological budget matched.

The initial screening metric is modal spectral span. It is deliberately insufficient for a WPT claim. A larger span does not imply higher efficiency.

## Initial observation

Under L=10 uH, C=100 nF and k=0.08, the star class has the largest modal span among the six tree classes. That is a **bounded computational observation**, not novelty and not a physical performance result.

This is scientifically useful because the search can rediscover a simple classical topology instead of being biased toward a fractal candidate.
