# Ω Multidirectional Omni Compiler — R1

R1 materializes the first domain IRs and a bounded executable cross-domain path.

## Implemented

- `CodeIR`, `GitIR`, `DocumentIR`, `SpecIR`.
- Validation for required provenance and domain-specific fields.
- `SpecIR -> CodeIR -> GitIR -> DocumentIR -> Artifact candidate` adapters.
- Reverse `Artifact candidate -> DocumentIR` fixture preserving document structure.
- Deterministic bidirectional `TransformationReceipt` hashes.
- Tests for the full bounded path.

## Important boundary

The R1 `Artifact` is an `application/pdf-candidate` with status `CANDIDATE_NOT_RENDERED`. R1 does not claim a real PDF renderer, PDF parser, visual fidelity, or file-level round-trip. The reverse adapter is a provenance-preserving fixture used to test the domain graph before the PDF layer is attached.

## Invariants

- `Generated != Verified`
- `ArtifactCandidate != PDF`
- `DeclaredTest != ExecutedTest`
- `GitIR != GitHubState` unless populated from an exact GitHub read
- `ReverseFixturePASS != PDFReversePASS`
