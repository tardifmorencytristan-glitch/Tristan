# Ω Scientific Writing Compiler — R2

R2 turns the R4 Living Delta benchmark into a conservative `ThesisState` and a first R5 candidate structure.

## Implemented

- `compile_r4_manifest`: converts D1–D8 into eight OBSERVATION claims.
- Each claim points to snapshot-level evidence with explicit uncertainty and a falsifier.
- R4 open frontiers become explicit residuals.
- `build_r5_candidate`: projects the ThesisState into a candidate R5 structure without epistemic promotion.
- Tests require exact preservation of the claim set and `no_status_upgrade=true`.

## Epistemic boundary

R2 does not reclassify R4 engineering reports as scientific proof. It only states that the R4 snapshot reported a given crystallization/status/commit. Underlying commits, receipts, experiments, literature and measurements must be re-read before promotion.
