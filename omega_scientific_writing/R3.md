# Ω Scientific Writing Compiler — R3

R3 upgrades the research compiler from structural linting to conservative scientific semantics.

## Implemented

- `scientific_types.py`: typed scientific claims with evidence-kind compatibility gates.
- Explicit blocker for engineering/software evidence being treated as sufficient physical evidence.
- `proof_obligations.py`: claim-type-specific proof obligations and open-obligation reporting.
- `epistemic_diff.py`: semantic diff for added/removed claims, status changes, evidence changes and scope changes.
- `exact_evidence.py`: exact-commit evidence adapter that fails closed and forbids promotion unless exact commit, independent receipt and explicit promotion authorization are all present.
- Exact evidence pilot for R4 D2 and D5 using observed canonical Git commits.
