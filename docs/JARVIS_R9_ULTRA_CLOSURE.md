# Jarvis R9 - Ultra Closure

Status: PROVISIONAL ENGINEERING IMPLEMENTATION.

R9 converts the current Tristan kernel from a collection of closure mechanisms into one bounded closure control plane. It reuses existing owners where they already exist and only adds contracts that were still missing.

## Canonical loop

`Reality -> Context* -> Residual -> MissionGenome -> CapabilityCoverage -> MinimalCoalition -> Execute -> Evidence -> Govern -> CausalCredit -> Distill -> CapabilityCrystal -> Regenerate`

## New canonical contracts

### MissionGenome

The universal work-unit contract contains:

- goal and explicit residuals;
- minimum context references;
- required capabilities;
- constraints and authority scope;
- evidence contract;
- five-origin candidate court: TRISTAN / SIMPLE / EXTERNAL / HYBRID / NO_ACTION;
- falsifiers;
- stop rules;
- rollback;
- multidimensional debt.

MissionGenome is planning structure only. It does not authorize execution.

### CapabilityCrystal

A stable capability must declare:

- interface;
- domain;
- evidence;
- dependencies;
- limits;
- falsifiers;
- regeneration recipe;
- provenance;
- version;
- RightToLose.

A CapabilityCrystal is not a scientific certification.

### Proof-Carrying Research Object

The PCRO contract binds claims, data, code, environment, evidence, negative results, falsifiers, provenance, limitations and replication state. It remains scientific_pass=false until an appropriate external scientific promotion process exists.

## Generation throttle

The runtime invariant is:

`GenerationRate <= VerificationRate + ClosureRate + DebtAbsorptionRate`

When violated, R9 lowers generation budget and raises closure budget.

## Regime controller

The current bounded modes are:

- EXPLORE
- VERIFY
- CLOSE
- REALITY

R9 defaults toward CLOSE when backlog/evidence debt dominate and toward REALITY when reality debt or verified demand dominate.
