# Status

R0.1 is a **PROVISIONAL ENGINEERING BOOTSTRAP**.

The kernel can represent and route a small federated registry, emit bounded context/run receipts, and verify repository structure. It does not yet perform network retrieval, external experiments, scientific promotion, automatic merges, or autonomous authority-bearing actions.

## Current residuals

- qualify this exact PR head in GitHub Actions;
- decide repository license separately;
- add evidence/receipt persistence only after the bootstrap court passes;
- benchmark the simple token-overlap `Context*` baseline before introducing embeddings or graph retrieval;
- add external source adapters only when a concrete task requires them;
- keep historical/private corpora federated rather than copied by default.
